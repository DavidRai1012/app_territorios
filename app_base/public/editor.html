Editor de territorios

Ajusta el contorno de cada zona y descarga el JSON para la app.

Cómo se usa
  • Arrastra un círculo blanco para mover un vértice.
  • Toca un punto pequeño entre dos vértices para añadir uno nuevo.
  • Doble clic o clic derecho en un vértice lo borra.
  • Activa «Vista previa de la app» para ver cómo se verá sin las herramientas.
  • Los cambios se guardan solos en este navegador.
